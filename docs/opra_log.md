# OPRA request log

**Status: drafted, not sent.** No public records request data is in the
dashboard. The request below was written with the help of Claude AI on
October 6, 2026. An AI tool cannot file a records request for you; the
person whose name is on the request has to send it.

## Why this request

The dashboard shows what Ewing spends on road upkeep per mile and what it
budgets for public works. It cannot show repaving, which is paid for
through the capital budget and is in none of the dashboard's measures.
The township's paving records would fill that gap. They would let the
dashboard add one line: at the number of miles repaved each year, how many
years would it take to repave all 109.68 miles of township road once?

## Who to send it to

The records custodian for a municipality is usually the municipal clerk.
Use the request form on the Ewing Township website. A letter or email
works only if it includes everything the form asks for.

## Exact wording of the request

> Under the Open Public Records Act, I request electronic copies of the
> following records, in Excel or CSV format if they are kept that way:
>
> Records identifying the streets resurfaced under the Township's road
> improvement program in each of the calendar years 2021, 2022, 2023, 2024
> and 2025, such as the annual road program list, or the bid specifications
> or contract award documents that list the streets and the limits of
> work.
>
> This request is not for a commercial purpose. Please let me know of any
> charge before filling this request.

Notes on the wording:

- It asks for records that should already exist (program lists, bid
  documents), not for an answer to a question. "How many miles did Ewing
  pave?" could be denied as a request for information.
- It names a reasonable range of dates.
- It asks for a spreadsheet if one exists, and to be told about charges
  first.
- It asks for nothing about any individual.

## How the records would be used

If the records arrive as a list of streets with lengths, one more script
would add up miles repaved per year and the dashboard would gain one
figure. There is no statewide source for this, so it would be compared
with Ewing's own earlier years, not with other towns.
